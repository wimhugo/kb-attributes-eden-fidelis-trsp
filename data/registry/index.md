# Registries

Many entities lack formal registries (standards, PIDs, etc.). 

This folder contains working examplars of such registries as placeholders for real-world implementations, and provide stable IRIs for referencing these standards in repository and service properties.

|Registry|Description|Link|
|--------|-----------|----|
|Standards|Standards applicable in the context of RDMI|[standards.ttl]()|
|Affiliations|Repository Affiliations|[affiliations.ttl]()|
|Packages|Exchange Packages|[packages.ttl]()|
|Package Transformation|Crosswalks and Transformations|[package_transforms.ttl]()|
