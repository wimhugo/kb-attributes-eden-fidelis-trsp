## Interpretation

Class boxes list properties having an explicit `rdfs:domain` equal to that class. Associations are drawn where both an explicit TRSP class domain and TRSP class range are present. Reusable properties that deliberately omit `rdfs:domain` are listed separately rather than being assigned an inferred domain. Dashed external inheritance links identify classes outside the TRSP namespace.
