# Provenance

Provenance is managed explicitly in the TRSP-EDEN-FIDELIS Knowledge Base (TEF-KB) using the PROV vocabulary with specific extensions. The provenance records are maintain in this folder, and can be combinied with other Knowledge Graph elements to provide provenance nodes in the TEF-KB.

Individual automated curation routines each maintain a separate provenance record, and when they are re-run, they can e instructed to overwrite, update, or append to an existing provenance file for that routine.
